# 七种写作方法：用途、操作与验收

本文件是本 Skill 的工作解释，不把七种方法说成同一套历史来源或同一层级。图解见仓库首页的[七种方法总览](../../docs/seven-structures.svg)。用户指定某一种方法时，以该方法为主；没有指定时，先逐一诊断，再选主结构与辅助方法。

## 共同工作表

对每种方法都填写四项，避免只给定义：

| 字段 | 需要回答 |
|---|---|
| 这本书的适用问题 | 当前最缺的是分段、不可逆转的高点、连续得失、人物变化、关键节点、节拍，还是扩写资料？ |
| 落到故事的动作 | 写出该方法会如何移动、补足或检验一个**具体情节**。 |
| 产出物 | 明确一张表、一条曲线、一组节点或一份扩写资料。 |
| 适配边界 | 哪个重要问题仍由其他方法或作者决定？ |

“适合/不适合”不等于给故事打分。说明的是**这个方法眼下能解决什么问题**。

## 诊断路由

先找会阻断下一阶段写作的主要缺口，再选择主方法；辅助方法只解决与主方法不同层级的缺口。没有足够情节材料时先用雪花法扩写，待故事成形后再判断节点和节奏。用户已指定主方法时遵从。

| 观察到的缺口 | 优先检查 | 判断依据 |
|---|---|---|
| 有几个强事件，连接靠巧合 | 七点故事结构 | 事件之间缺少人物决定造成的因果。 |
| 一个阶段的信息层层增加，却没有重释 | 起承转合 | “转”未改变读者对前文的理解。 |
| 卷级冲突始终没有不可退回的高点 | 金字塔 | 压力虽增加，高潮后的局面没有变化。 |
| 中段事件可随意删改顺序 | 冲突曲线 | 得失未改变资源、关系、目标或规则。 |
| 主角经历很多，最后仍以旧方式行动 | 英雄之旅 | 重大考验没有转化为新的选择。 |
| 开篇承诺与中段、结局脱节 | 救猫咪节拍 | 读者被吸引来的核心看点长期缺席。 |
| 只有设定或一句话点子，缺人物与场景资料 | 雪花写作法 | 还没有足够材料安排因果节点。 |

选择结果必须附两句话：**为什么它是当前最主要的缺口**，以及**其他方法在此阶段只承担什么辅助职责**。不以凭空生成的数字分数表示“适配度”。

## 01 起承转合：用信息转向组织四段

- **适用**：故事的吸引力来自观察、关系变化或信息重释，尤其适合规划一个单元或一卷的整体走势。
- **操作**：写出「起」建立的状态与读者预期；「承」添加的细节和关联；「转」带来的新信息或新视角；「合」如何让前文获得新的意义。允许冲突存在，也允许主角没有典型的成长弧。
- **交付**：四段表，每段写新增信息、读者理解怎样改变、人物或局面怎样变化。长篇要再说明下一个单元如何在“合”之后起势。
- **验收**：「转」若只是再来一场更大的冲突，没有改变读者对前文的理解，应重新设计；「合」须回应前面埋下的关系或信息。

## 02 金字塔：设计压力高点与后果

- **适用**：已经知道故事冲突，但不清楚压力如何升级到不可回头的局面；适合作为卷级结构。
- **操作**：列出初始局面、引发事件、逐级加压、核心高点、此后的后果与新局面。每一级压力都由人物之前的行动或约束引出。高点可兼具高潮与不可逆转性，不强行规定悲剧收束。
- **交付**：一张压力来源、主角应对、代价、下一层压力表，并标明高点之后人物失去或获得了什么。
- **验收**：后半段若仅靠解释事件收尾，补写高点造成的行动后果。长篇不要把全书唯一高点放在第一卷。

## 03 冲突曲线：记录行动、得失与再升级

- **适用**：中段容易平直，事件虽多但没有积累后果。
- **操作**：以主角当前目标为基线，安排数轮「行动 → 部分成功或失败 → 资源、关系或规则改变 → 新目标」。波峰与波谷可以交错，不要求每次都比上次更惨。
- **交付**：至少三轮性质不同的得失表；同时写出每轮之后读者对胜算的判断怎样改变。
- **验收**：删除其中一轮后，如果后续剧情几乎不受影响，这轮尚未形成有效因果。
- **术语边界**：本 Skill 将“曲线”操作化为连续得失与处境变化的工作表，不声称它是某位作者唯一的标准版本。

## 04 雪花写作法：逐层扩展创作材料

- **适用**：一句话卖点已经成立，但人物、事件与章节之间缺乏可执行资料。
- **操作**：从一句话梗概，到一段式故事，再到主要角色的动机、目标、障碍与变化；继续扩成阶段梗概、人物视角梗概和场景清单。后层发现问题时回改前层。
- **交付**：一句话 → 一段式 → 主要角色卡 → 阶段梗概 → 场景或章节清单。用户以雪花法为主时展开全部规划层；若仅作辅助，先交付当前创作阶段需要的层级。
- **验收**：每次扩写应增加因果和人物选择；只增加设定名词不算扩写。雪花法是**设计文档流程**，不能单独替代高潮设计。
- **来源边界**：原作者 Randy Ingermanson 的公开说明包含十步，本 Skill 在开书规划阶段使用其中的设计层，正文写作留给下一阶段。

## 05 英雄之旅：检查离开、考验与归来

- **适用**：人物如何改变是故事的主要阅读承诺。
- **操作**：写出角色的旧位置、离开的门槛、进入新局面后的考验，以及带着何种能力或认识返回。多主角时分别追踪，避免一人只是另一人的奖励。
- **交付**：人物变化表：起初的信念或做法、被迫跨过的门槛、考验中的选择、归来后与旧状态的区别。
- **验收**：结局若只有外部胜利，人物却仍用旧方式处理同一问题，变化线尚未完成。没有必要套齐所有流行的十二或十七个小步骤。
- **来源边界**：Joseph Campbell Foundation 将核心概括为离开、启蒙、归来；其他细节是可变的。

## 06 七点故事结构：固定全书的因果转折

- **适用**：手里已有多个好情节，但这些情节之间尚未形成一条可推进的主线。
- **操作**：先确定终局，再反推起点和中点，补上第一次转向、两次压力点与第二次转向。七点须写明前一节点怎样造成或迫使下一节点发生。
- **交付**：起点 Hook、第一转折 Plot Turn 1、第一压力 Pinch 1、中点 Midpoint、第二压力 Pinch 2、第二转折 Plot Turn 2、终局 Resolution，七行表每行包含事件、人物决定、状态变化。
- **验收**：中点应改变主角处理问题的方式；第二转折应让终局的行动成为可能。若七个节点之间需要许多无因果的偶遇，重新设计连接。

## 07 救猫咪节拍：核对承诺与兑现

- **适用**：故事起点和终局都清楚，但读者体验中的承诺、中段变化与最低点不够明确。
- **操作**：以十五节拍检查开场画面、主题提示、铺垫、催化剂、争辩、进入第二幕、副线、核心看点、中点、压力逼近、重大失去、低谷、进入第三幕、终局与终场画面。写出每个节拍在本书里对应的**功能**，不硬套固定字数或页码。
- **交付**：主结构选择它时输出十五行节拍表；仅作辅助时重点检查开场承诺、中点变化、重大失去、最终兑现。
- **验收**：终场画面应让读者看到开场状态的变化；若“核心看点”长期没有兑现，说明读者承诺和实际内容脱节。
- **来源边界**：Save the Cat! 的官方工具提供十五节拍和小说选项；本 Skill 的长篇使用法是适配，不是官方授权版本。

## 长篇组合规则

1. **全书层**：选一个主方法确定最终变化；指定主方法时尊重用户选择。
2. **分卷层**：每卷说明阶段目标、阶段损失或收获、不可退回的变化。需要时用金字塔或冲突曲线检验连续推进。
3. **人物层**：说明主角怎样改变或为何保持不变；不要强迫所有人物完成同一种弧线。
4. **章节层**：前三章只落实开篇承诺与下一步悬念；没有足够资料时不假装已经排好全书章节。
5. **交付门槛**：七种方法都须对当前故事产生具体判断；选中的主方法按上面对应的完整交付要求展开；新增设定均标注为提案。

## 方法来源与本仓库的改编边界

本仓库的图解、工作表与长篇应用方式为原创整理。以下资料用于核对方法的基本概念；不表示相关作者或机构认可本 Skill：

- 起承转合的跨文化叙事讨论：Gabriel Oh, [*Kishōtenketsu and its potential applications to prose writing*](https://textjournal.scholasticahq.com/article/146391-kishotenketsu-and-its-potential-applications-to-prose-writing), *TEXT*, 2025。本文讨论的是相关的起承転結，不把它与中文起承转合完全等同。
- 金字塔的历史文本：Gustav Freytag, [*Die Technik des Dramas*](https://www.gutenberg.org/ebooks/50616)。本 Skill 将戏剧弧线改作长篇卷级压力检查。
- 雪花写作法：Randy Ingermanson, [*How to Write a Novel Using the Snowflake Method*](https://www.advancedfictionwriting.com/articles/snowflake-method/)。
- 英雄之旅：[Joseph Campbell Foundation 的方法说明](https://www.jcf.org/learn/joseph-campbell-heros-journey)。
- 七点故事结构：[Dan Wells 的公开讲座](https://www.youtube.com/watch?v=KcmiqQ9NpPE)。
- 救猫咪节拍：[Save the Cat! 官方十五节拍工具](https://savethecat.com/beat-mapper)。

“冲突曲线”在本仓库中采用上文的操作定义，未指定单一理论来源。使用时应说明这是工作模型，避免把多种曲线理论混写成同一位作者的原始方法。
